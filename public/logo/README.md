# Direktori Logo & Gambar LITENSI KIDS

Folder ini disiapkan khusus untuk menyimpan aset gambar dan logo aplikasi.

### Cara Menggunakan File Logo:
1. Simpan/upload file logo Anda ke dalam folder ini:
   - Rekomendasi nama file: `logo.png`, `logo.svg`, atau `litensi-logo.png`
   - Path absolut: `/public/logo/logo.png`
2. Di dalam kode aplikasi, file ini dapat langsung diakses melalui URL:
   - `/logo/logo.png` (atau `/logo/nama-file-anda.png`)
